How Norra, our robot receptionist, is built

Norra greets visitors, tells their host they have arrived, prints a visitor badge and walks guests to the waiting room. It does this with three parts working together: an app on the robot, a small office server, and the company tools we already use.

The big picture

Read from left to right. People talk to the robot, the robot asks the office server for help, and the server talks to Microsoft 365 and email. The grey text in each box shows where that part lives in the code repository.

One visit, step by step

What happens when a guest with an appointment walks in. The coloured line shows which part does the work.

  1. Guest arrives

    Norra asks "How can we help you?" The guest answers by voice or taps a button.

    Visitor
  2. Norra understands

    Detects German or English and picks up the guest's name and who they are meeting.

    Robot app
  3. Host is told

    The server finds the host in the staff list and sends them an email.

    Office server + email
  4. Badge is printed

    Norra takes a photo and prints a badge with name, host and QR code.

    Robot app + printer
  5. Walk to waiting room

    Norra drives the guest to the waiting room and offers a short story about the company.

    Robot app

Two robot apps in one repository

The repository holds two separate products. They run on the same kind of robot but do not share code or settings, so both can be installed side by side.

Main product

Smart Receptionist (Norra)

The full reception experience shown above: check-in, host notifications, bookings, deliveries, badges and guiding. Needs the office server.

android/ + backend/
Spin-off for events

Wayfinder

A simpler guide robot for event visitors. It shows room tiles, walks people there, explains which floor a room is on, and wanders around to invite people when idle. Works on its own, without a server.

wayfinder/

Installed on robot

Staff install it; the app can also check for updates itself.

The office server runs on a laptop in the office for now. It can also run in the cloud (Render), but the free plan wipes badges and the visitor log on every update, so a paid plan with storage is needed for real use.
